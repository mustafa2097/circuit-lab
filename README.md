# مختبر دوائر PLC

محاكي تعليمي لتركيب دوائر الريليه/PLC مطابقة للملزمة.

## التشغيل

```bash
cd circuit-lab
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000)

للـ QR بروابط صحيحة على الشبكة المحلية:

```bash
set NEXT_PUBLIC_BASE_URL=http://YOUR_LAN_IP:3000
npm run dev
```

## الاستخدام

1. اختر دائرة أو امسح QR
2. اسحب القطع واربِط المنافذ كما في الملزمة (الكيبل الأخضر المتقطع يرشدك)
3. عند اكتمال الربط اضغط **تشغيل** وجرّب الأزرار

## البيانات

- `data/catalog.json` — الفهرس
- `data/circuits/*.json` — تعريف كل دائرة (قطع، أسلاك مرجعية، خطوات، محاكاة)
